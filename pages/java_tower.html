    Trial of the Java Tower

    Grade: 20/20

    Object-oriented platformer made in Java as the final project for Object-Oriented Programming course (Programação Orientada a Objetos).


    The player must climb the tower while defeating enemies, collecting items, and dodging obstacles to save the princess while trying to achieve a high score.
